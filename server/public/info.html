To compile, clone the repo then:

cd client
cmake --build build

The convention for the id is [your name]-[algorithm] (i.e. simon-rect). Make sure to set the algorithm in the dashboard if not set already. The current algorithms are rect (recommended) and square.

To connect, run:

DISTRIBUTED_PRIMES_CLIENT_ID=[PUT AN ID HERE!!] ./build/distributed_prime_client primes.simon312.hackclub.com:8080
